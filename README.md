# Knotz Bizarre Escape

A Metal Slug / Contra-inspired run-and-gun, rebuilt from scratch in **Phaser 4** (TypeScript + Vite).
The original 2023 pygame version is preserved in [`archive/pygame-original/`](archive/pygame-original/).

## Run
```sh
cd game
npm install
npm run dev        # http://127.0.0.1:8080
npm run build      # production build in game/dist
```
