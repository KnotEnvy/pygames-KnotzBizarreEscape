# Knotz Bizarre Escape

A Metal Slug / Contra-inspired run-and-gun, rebuilt from scratch in **Phaser 4.2.1** (TypeScript + Vite).
Escape the Bizarre Regime's mountain prison camp, fight through the pine forest, river bridge and outpost, and
take down **MOOSEZILLA**. The original 2023 pygame version is preserved in [`archive/pygame-original/`](archive/pygame-original/).

## Run
```sh
cd game
npm install
npm run dev        # http://127.0.0.1:8080  (dev mode: cheats/debug URLs enabled)
npm run build      # production build in game/dist (static files, relative paths)
npm run preview    # serve the production build on http://127.0.0.1:4173
```

## Controls
| Action | Keyboard | Gamepad |
|---|---|---|
| Move / aim (8-way) | Arrow keys | D-pad |
| Jump | Z or Space | A |
| Shoot / knife (up close) | X or J | X |
| Grenade | C or K | B |
| Aim-lock (stand still, aim freely) | Shift or L | RB |
| Pause | Esc or Enter | Start |

Up+fire shoots up, diagonals while moving, Down in the air shoots down, Down on the ground crouches.
Down+Jump drops through thin platforms. Keys can be rebound in **Options → Controls**.

## Playtest guide
- Start from the title screen, and choose **Difficulty: Arcade** (one hit = one life, the real Metal Slug feel) or **Casual** (3 HP per life).
- Options include music and SFX volume, a CRT filter, screen shake, reduced flash and mute.
- Handy dev URLs (dev server or `?debug=1`):
  - `?scene=Game&fast=1`: skip the title and intro.
  - `&x=<px>`: start at a position. Camp `400`, forest `1900`, rope bridge `2800`, bridge arena `3080`, outpost `4200`, bunker arena `5000`, boss gate `6200`.
  - `&god=1`: invulnerable. `&difficulty=casual`: Casual mode. `&mute=1`: no sound. `&debug=1`: debug overlay (F2 toggles it) and cheats.
  - Console: `__KBE.cheats.give('hmg'|'spread'|'rocket'|'flame')`, `__KBE.cheats.boss()`, `__KBE.state()`.
- **The feedback we most need** (things automated tests can't judge):
  1. **Difficulty** in Arcade: where did you die, and was each death fair (did you see it coming)?
  2. **Feel**: run and jump weight, shooting punch, knife, grenades, hitstop and shake.
  3. **Audio mix**: music vs effects balance, anything too loud, too quiet or annoying (the HMG especially).
  4. **Readability**: could you always see enemy bullets and yourself in the busy fights?
  5. **Performance on your GPU**: any stutter? (The debug overlay shows FPS.)
  6. Gamepad, if you have one.
  7. Anything that made you grin, and anything that made you groan.

## Tooling
- `npm run check`: typecheck plus the Phaser 4 API linter. `npm run selftest`: engine self-test. `npm run test:e2e`: Playwright suite.
- `node tools/shot.mjs --out /tmp/x.png --query "scene=Game&fast=1"`: headless screenshot and drive tool.
- `bash tools/build-art.sh`: rebuild all Aseprite art from the Lua sources in `art-src/`. The map is generated from
  `art-src/maps/build_stage1.mjs` (Tiled 1.12). Audio is generated by `tools/audio/build.sh` (all synthesized, no samples).

All art, audio and code in `game/` are original to this project. The legacy pygame assets in `archive/` have no
documented license and aren't used by the new game.
